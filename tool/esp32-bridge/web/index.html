Tama Bridge flasher

Puts the Tama Bridge firmware on an ESP32 from this page: plug the board in with a USB data cable, pick it below, choose its port. Works in Chrome or Edge on a computer (not Safari, not phones).

Any ESP32 board

ESP32 (T-LoRa, DevKit), ESP32-C3, ESP32-S3, ESP32-C6: the chip is recognised and the matching firmware written.

Wiring

BoardBridge RX (from toy TX)Bridge TX (to toy RX)
ESP32 (T-LoRa v1.3, DevKit)GPIO 34GPIO 13
ESP32-C3GPIO 20GPIO 21
ESP32-S3GPIO 44GPIO 43
ESP32-C6GPIO 17GPIO 16
Heltec V3 / V4GPIO 47GPIO 48

Plus GND to GND. Three wires only: do not connect the toy's power. Not the ESP32-S2 (no Bluetooth). If the board is not found: install its USB driver (CP210x or CH340), or hold BOOT while plugging it in.

Then in the Tama app: Tools → Dongle to change its settings, Tools → Hardware to use it. A Windows flasher (no browser needed) is on the Releases page.
